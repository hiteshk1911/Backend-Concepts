- Authorization Server (our own microservice) — issues JWT access tokens and refresh tokens, exposes JWK set and token endpoints and consent UI.

- Resource Server (a mock Gmail Contacts API) — serves a protected /contacts endpoint which accepts the access token issued by our Authorization Server.

- Client (Print App) — a web app that acts as an OAuth client. It starts the Authorization Code flow, receives the code, exchanges it for tokens, calls /contacts and displays printable contacts.

- Resource Owner (User) — simulated via an in-app login (users stored in memory) — when client redirects to Authorization Server the user logs in and gives consent.

Note: this is a local demo. We mock a Gmail-like resource server (contacts) rather than calling real Gmail APIs. The OAuth2 flow and token validation are identical to production usage.

We’ll run them on these ports:

Authorization Server: http://localhost:9000

    Authorization endpoint: /oauth2/authorize (Spring built-in)
    Token endpoint: /oauth2/token
    JWK set: /.well-known/jwks.json
    Login and consent UI served from this app.

Resource Server (Contacts API): http://localhost:9100

    Protected API: GET /api/contacts

Client (Print App): http://localhost:8080

Redirect URI configured: http://localhost:8080/login/oauth2/code/print-client
Home / with "Connect to Contacts" button and page to display contacts.

We will configure a client in the Authorization Server called print-client with:

    client_id: print-client
    client_secret: secret (for demo; in production use stronger secret or use PKCE for public clients)
    redirect_uri: http://localhost:8080/login/oauth2/code/print-client
    authorization_grant_type: authorization_code, refresh_token
    scope: contacts.read

Access tokens will be JWTs signed by the Authorization Server; Resource Server will validate tokens using the Authorization Server's JWKs endpoint.

package com.example.authserver.config;

import java.security.KeyPair;
import java.security.KeyPairGenerator;
import java.security.interfaces.RSAPrivateKey;
import java.security.interfaces.RSAPublicKey;
import java.util.UUID;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.crypto.factory.PasswordEncoderFactories;
import org.springframework.security.crypto.password.PasswordEncoder;

import org.springframework.security.oauth2.core.AuthorizationGrantType;
import org.springframework.security.oauth2.jwt.*;
import org.springframework.security.oauth2.server.authorization.*;
import org.springframework.security.oauth2.server.authorization.client.*;
import org.springframework.security.oauth2.server.authorization.config.ProviderSettings;
import org.springframework.security.web.SecurityFilterChain;

import com.nimbusds.jose.jwk.*;
import com.nimbusds.jose.jwk.gen.RSAKeyGenerator;

@Configuration
public class AuthorizationServerConfig {

    @Bean
    public RegisteredClientRepository registeredClientRepository(PasswordEncoder passwordEncoder) {
        RegisteredClient printClient = RegisteredClient.withId(UUID.randomUUID().toString())
                .clientId("print-client")
                .clientSecret(passwordEncoder.encode("secret"))
                .redirectUri("http://localhost:8080/login/oauth2/code/print-client")
                .authorizationGrantType(AuthorizationGrantType.AUTHORIZATION_CODE)
                .authorizationGrantType(AuthorizationGrantType.REFRESH_TOKEN)
                .scope("contacts.read")
                .clientSettings(ClientSettings.builder().requireAuthorizationConsent(true).build())
                .build();

        return new InMemoryRegisteredClientRepository(printClient);
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return PasswordEncoderFactories.createDelegatingPasswordEncoder();
    }

    // provider settings (issuer)
    @Bean
    public ProviderSettings providerSettings() {
        return ProviderSettings.builder().issuer("http://localhost:9000").build();
    }

    // configure endpoints & security filter chain
    @Bean
    public SecurityFilterChain authServerSecurityFilterChain(HttpSecurity http) throws Exception {
        OAuth2AuthorizationServerConfiguration.applyDefaultSecurity(http);
        // allow form login for user authentication
        http
            .formLogin(Customizer.withDefaults());
        return http.build();
    }

    // JWK source (RSA)
    @Bean
    public JWKSource<com.nimbusds.jose.proc.SecurityContext> jwkSource() throws Exception {
        RSAKey rsaKey = new RSAKeyGenerator(2048)
                .keyID("auth-server-key")
                .generate();
        JWKSet jwkSet = new JWKSet(rsaKey);
        return (jwkSelector, securityContext) -> jwkSelector.select(jwkSet);
    }

    // OAuth2AuthorizationService and AuthorizationConsentService can be default in-memory beans
}

//HomeController.java

package com.example.clientapp.controller;

import java.util.List;
import java.util.Map;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.*;
import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.security.core.Authentication;
import org.springframework.security.oauth2.client.*;
import org.springframework.security.oauth2.client.authentication.OAuth2AuthenticationToken;
import org.springframework.security.oauth2.client.annotation.RegisteredOAuth2AuthorizedClient;
import org.springframework.security.oauth2.core.*;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.client.RestTemplate;

@Controller
public class HomeController {

    private final OAuth2AuthorizedClientService clientService;
    private final RestTemplate restTemplate = new RestTemplate();

    @Autowired
    public HomeController(OAuth2AuthorizedClientService clientService) {
        this.clientService = clientService;
    }

    @GetMapping("/")
    public String index(Model model, Authentication authentication) {
        boolean loggedIn = authentication != null && authentication.isAuthenticated();
        model.addAttribute("loggedIn", loggedIn);
        return "index";
    }

    @GetMapping("/print")
    public String print(Model model, OAuth2AuthenticationToken authentication) {
        if (authentication == null) {
            return "redirect:/";
        }

        String registrationId = authentication.getAuthorizedClientRegistrationId();
        String principalName = authentication.getName();

        OAuth2AuthorizedClient client = clientService.loadAuthorizedClient(
                registrationId, principalName);

        if (client == null) {
            return "redirect:/";
        }

        OAuth2AccessToken accessToken = client.getAccessToken();
        String tokenValue = accessToken.getTokenValue();

        HttpHeaders headers = new HttpHeaders();
        headers.setBearerAuth(tokenValue);

        HttpEntity<Void> request = new HttpEntity<>(headers);
        ResponseEntity<List> response = restTemplate.exchange(
                "http://localhost:9100/api/contacts",
                HttpMethod.GET,
                request,
                List.class
        );

        List<Map<String,String>> contacts = response.getBody();
        model.addAttribute("contacts", contacts);
        model.addAttribute("tokenExpiresAt", accessToken.getExpiresAt());
        return "print";
    }
}

=> How the flow works in this demo

    User visits http://localhost:8080 and clicks Connect.
    Spring Security builds the authorization request and redirects the user to the Authorization Server at http://localhost:9000/oauth2/authorize with parameters including client_id=print-client, redirect_uri=http://localhost:8080/login/oauth2/code/print-client, response_type=code, scope=contacts.read, state=....
    Authorization Server shows login page — user logs in as alice/password (from in-memory store).
    Authorization Server shows consent page (because we configured requireAuthorizationConsent(true)), user approves scopes.
    Auth server redirects back to client http://localhost:8080/login/oauth2/code/print-client?code=...&state=....
    Spring Security client auto-exchanges the code at http://localhost:9000/oauth2/token using the client credentials (print-client/secret) and receives an access token (JWT) and a refresh token.
    Client stores authorized client and its tokens in OAuth2AuthorizedClientService (in-memory).
    When user clicks /print the client retrieves the authorized client and its access token and calls http://localhost:9100/api/contacts with Authorization: Bearer <access_token>.
    Resource Server validates JWT by fetching JWKs from http://localhost:9000/.well-known/jwks.json, validates signature, scope and expiry. If valid, responds with contacts JSON.

Important security notes & production considerations

    This demo is for learning and local testing. In production you must:

    Use HTTPS everywhere. Never use plain HTTP for OAuth flows in production.
    Use secure, strong client secrets; use PKCE for public clients (mobile, SPA) — PKCE prevents intercepted authorization codes from being used.
    Use long-lived refresh tokens carefully (rotate them, bind them to clients, revoke on suspicious use).
    Use proper persistent stores for registered clients, authorizations and consents (DBs) rather than in-memory.
    Add proper CSRF protections and validate state parameter.
    Limit scopes to minimal needed. Monitor and audit token issuance.
    Rotate signing keys and expose JWK set.
    Implement token introspection / revocation endpoints if needed.
    Configure session and cookie security, same-site attributes, etc.
    Quick explanation of key code pieces (so you fully understand)
    RegisteredClientRepository: registers OAuth clients (here print-client). Settings include allowed grant types, redirect URIs, scopes and whether consent is required.

    JWKSource: provides RSA keys to sign JWT access tokens. Authorization Server exposes the public key (/.well-known/jwks.json), Resource Server fetches it to validate signatures.

    Authorization Server endpoints: Spring Authorization Server creates /oauth2/authorize and /oauth2/token. Login and consent steps are standard.

    Resource Server: configured to fetch JWK set URI and validate incoming Authorization header tokens automatically using spring-boot-starter-oauth2-resource-server.

    Client: Spring Security OAuth2 Client handles building the authorization redirect, exchanging the code for tokens, and storing the OAuth2AuthorizedClient. We used OAuth2AuthorizedClientService to fetch tokens to call resource server.

Extensions you can add

    Switch to asymmetric key rotation using keystore and exposing multiple keys via JWK set.
    Add OpenID Connect support (userinfo endpoint, openid scope) — then client can get ID token and user profile.
    Implement PKCE (especially if making the client public).
    Use a database-backed RegisteredClientRepository (e.g., JDBC) for dynamic client registration.
    Add token revocation and introspection endpoints.
    Replace static in-memory user store with a real user database and integrate multi-factor auth.
